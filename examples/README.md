# Examples

Curated notebooks. Run them from the repo root after `pip install -e ".[train]"` so `from nlse import *` resolves.

| Notebook | Topic |
|---|---|
| `01_nlse_target_pulses.ipynb` | Single-field NLSE inverse design |
| `02_xpm_solver.ipynb` | Coupled XPM split-step |
| `03_hg_basis.ipynb` | Hermite–Gauss basis |
| `04_xpm_drift.ipynb` | Walk-off / drift XPM |
| `05_identity_unitary.ipynb` | Identity-operator prototype |

Scratch work lives in `../notebooks/`. Older notebooks are in `../archive/notebooks/`.
